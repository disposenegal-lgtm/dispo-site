# Affiches Dispo × HP Color LaserJet Pro MFP 4303

Trois designs A4 prêts à imprimer, dans `export/` (PDF A4 + JPG 300 dpi) :

| Fichier | Style |
|---|---|
| `affiche-1-bureau` | Bleu nuit, titre géant « 4303 », 6 tuiles de caractéristiques |
| `affiche-2-nuit` | Noir et rouge Dispo, lignes lumineuses, produit centré |
| `affiche-3-epure` | Blanc épuré, cartes de caractéristiques, encadré contact |

Logos : `images/logo-dispo.png` (le vôtre, fond retiré) et `images/logo-hp.svg`
(une version simplifiée : remplacez-la par le fichier officiel HP si vous l’avez, en gardant le même nom).

Régénérer les exports après modification : `node render.js affiche-1-bureau affiche-2-nuit affiche-3-epure`
