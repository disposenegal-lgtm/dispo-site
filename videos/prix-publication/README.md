# Vidéo TikTok « Le prix est sur la publication »

Sketch vertical (1080x1920, 19 s) avec le lapin Dispo :

1. POV : la publication HP 304, « le prix est sur la publication… mais le client demande QUAND MÊME »
2. Discussion WhatsApp : « Bonjour c'est combien ? » → « 4.000.000 » → « Pourtant c'est écrit 3.500.000 sur la publication » → « Ah… vous avez vu le prix donc »
3. Lapin clin d'œil : « AH… VOUS AVEZ VU LE PRIX DONC ? »
4. Carte de fin : www.dispo.sn + numéros

La vidéo est **muette** : ajoutez le son tendance dans TikTok (« Ajouter un son ») au moment de publier.

Pour modifier le texte ou les prix : éditez `DIALOGUE` dans `make_video.py` puis `python3 make_video.py`.
